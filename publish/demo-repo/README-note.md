## Reviewing this repository with Fathom

This history is a fixture: every commit exists to put a row somewhere in
[Fathom](https://github.com/danielstahl/fathom). [`DEMO.md`](DEMO.md) is the five-minute tour, and
`.github/workflows/fathom.yml` is the gate running on it — five lines that call Fathom's reusable
workflow, the same five any repository can copy.
