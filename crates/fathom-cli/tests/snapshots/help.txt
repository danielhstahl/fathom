===== fathom --help =====
Review an agent-driven repository before it merges.

Usage: fathom [OPTIONS] [COMMAND]

Commands:
  index   Index the repository so every other verb has something to read
  show    Show one episode in full
  stats   Report repo scale, index state and cache hit rate
  check   Run the checks CI cares about; findings above the threshold exit 7
  doctor  Describe this build, its environment and its index, with a remedy per finding
  export  Write a review artefact for a pull request or an audit
  mcp     Speak MCP to a coding agent
  watch   Watch the repository and index as it changes
  hooks   Report on the harness event stream: lag, offset, rejections, replay (`e6.1`)
  tui     Print the terminal UI's keymap, or open the UI itself
  help    Print this message or the help of the given subcommand(s)

Options:
      --plain
          Draw as text, with no terminal taken: for pipes, CI logs and screen readers (ADR-006 §6.7).
          
          Chosen automatically when stdout is not a terminal, so a redirected run degrades by itself.

      --no-alt-screen
          Draw in place instead of taking the alternate screen, which keeps the shell's scrollback

      --fresh
          Ignore the session this repository has stored, and start from defaults (`e1.11`).
          
          The escape hatch for a session that came back wrong: a filter that hides the episode you are looking for, a cursor on a row that moved. The stored state is not destroyed — a run that changes nothing writes nothing — it is simply not applied to this one.

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

===== fathom index --help =====
Index the repository so every other verb has something to read

Usage: fathom index [OPTIONS] [ROOT]

Arguments:
  [ROOT]
          The repository to index
          
          [default: .]

Options:
      --plain
          Draw as text, with no terminal taken: for pipes, CI logs and screen readers (ADR-006 §6.7).
          
          Chosen automatically when stdout is not a terminal, so a redirected run degrades by itself.

      --stats
          Print the per-analyzer cache table (ADR-004 §4.8)

      --json
          Print the run report as JSON on stdout, and nothing else there

      --no-alt-screen
          Draw in place instead of taking the alternate screen, which keeps the shell's scrollback

      --fresh
          Ignore the session this repository has stored, and start from defaults (`e1.11`).
          
          The escape hatch for a session that came back wrong: a filter that hides the episode you are looking for, a cursor on a row that moved. The stored state is not destroyed — a run that changes nothing writes nothing — it is simply not applied to this one.

      --refresh
          Look up every stored unit, and recompute the ones that hit too.
          
          This is the pass that *measures* ADR-004 §6's invalidation matrix instead of trusting it: after a version or config bump it prints exactly the rows that moved, and after an unremarkable commit it prints 100% hits.

      --rebuild
          Throw the epoch away and rebuild every analysis from scratch.
          
          The old epoch's rows stay on disk and are marked dead (ADR-004 §6.3), so a rebuild that is interrupted is recoverable by definition; the staging file and atomic swap of §9.3 arrive with the daemon that has a concurrent reader to protect.

      --watch
          Index once, then keep watching and index as the repository changes.
          
          The one-shot form a script wants, and the same thing as `fathom watch` with an initial index.

      --committed-only
          Do not analyse uncommitted paths (ADR-004 §6.4)

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

===== fathom watch --help =====
Watch the repository and index as it changes

Usage: fathom watch [OPTIONS] [ROOT]

Arguments:
  [ROOT]
          The repository to watch
          
          [default: .]

Options:
      --json
          Print one JSON object per state change on stdout, and nothing else there

      --plain
          Draw as text, with no terminal taken: for pipes, CI logs and screen readers (ADR-006 §6.7).
          
          Chosen automatically when stdout is not a terminal, so a redirected run degrades by itself.

      --no-alt-screen
          Draw in place instead of taking the alternate screen, which keeps the shell's scrollback

      --once
          Index once, then exit: what a script or a CI check wants from `watch`

      --fresh
          Ignore the session this repository has stored, and start from defaults (`e1.11`).
          
          The escape hatch for a session that came back wrong: a filter that hides the episode you are looking for, a cursor on a row that moved. The stored state is not destroyed — a run that changes nothing writes nothing — it is simply not applied to this one.

      --max-cycles <MAX_CYCLES>
          Stop after this many looks at the filesystem

      --deadline <DEADLINE>
          Stop after this many seconds

      --backend <BACKEND>
          Which change source to use: `auto`, `notify` or `poll`
          
          [default: auto]

      --interval-ms <INTERVAL_MS>
          The debounced polling interval in milliseconds

      --debounce-ms <DEBOUNCE_MS>
          The quiescence window in milliseconds: how long the filesystem must be quiet before a change is read

      --heartbeat-ms <HEARTBEAT_MS>
          The liveness beat in milliseconds: how often the state is rewritten while nothing changes

      --chunk-units <CHUNK_UNITS>
          Analysis units per index chunk — the watcher's slice of the CPU
          
          [default: 2000]

      --worktree
          Also re-index uncommitted paths when only the index moved

      --no-status-file
          Do not write `.fathom/watch/status.json`

      --quiet
          Print nothing to stdout but errors; the state machine still goes to the status file

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
